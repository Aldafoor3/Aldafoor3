## About

**Full-stack developer.** I build web apps with Java, Spring Boot and Angular, from the database to the screen. Since May 2023 I work as a Junior Software Engineer at ITQ (Angular, C++, TypeScript, Python, HMI), alongside my studies in Applied Computer Science (Software Engineering) at the University of Duisburg-Essen.

**Machine learning.** For my bachelor project I built forecasting models for blood glucose in type 1 diabetes with PyTorch and scikit-learn, and rated them by clinical safety, not only by error. In a university course I built an AI web app that turns text, sketches and photos into 3D models.

**Languages.** Arabic (native) &middot; French &middot; English &middot; German (C1)
